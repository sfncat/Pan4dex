### ✅ 16.2 - 二进制文件比较

**实现内容：**
- 在 `widgets/file_compare.py` 中实现了完整的二进制比较功能
- 支持文本比较和二进制比较两种模式切换
- 逐字节对比两个文件，显示差异位置

**核心功能：**
- `compare_binary()` - 二进制比较主函数
- `show_binary_results()` - 显示比较结果
- `_group_differences()` - 将相邻差异分组
- `_format_hex_dump()` - 格式化十六进制输出
- `format_size()` - 文件大小格式化

### ✅ 18.4 - 支持 7z/rar 格式

**实现内容：**
- 在 `widgets/archive_tool.py` 中扩展了压缩包格式支持
- 新增 7Z 和 RAR 格式创建支持
- 自动检测系统上的 7-Zip 和 WinRAR 工具
- 提供友好的错误提示和下载链接
- 使用命令行工具进行压缩（跨平台）

**支持的格式：**
- ZIP（原生支持）
- TAR.GZ（原生支持）
- TAR.BZ2（原生支持）
- **7Z（新增）** - 使用 7z 命令行
- **RAR（新增）** - 使用 rar 命令行

**核心功能：**
- `_create_7z()` - 创建 7z 压缩包
- `_create_rar()` - 创建 RAR 压缩包
- `_find_7z()` - 查找 7z 可执行文件
- `_find_rar()` - 查找 rar 可执行文件

**依赖要求：**
- Windows: 需要安装 7-Zip 或 WinRAR
- Linux: 需要安装 p7zip-full 或 unrar

3. **集成点**
   - 右键菜单中可以调用自定义操作
   - 主窗口可以绑定全局快捷键
   - 支持基于文件类型的上下文菜单

**扩展建议：**
在对话框中添加快捷键字段：
```python
self.shortcut_edit = QKeySequenceEdit()
operation['shortcut'] = self.shortcut_edit.keySequence().toString()
```

## 使用说明

### 使用二进制比较
1. 打开文件比较对话框
2. 选择"二进制比较"模式
3. 选择两个文件进行比较
4. 查看十六进制差异报告

### 导出比较报告
1. 完成比较后点击"导出报告"
2. 选择 HTML 或文本格式
3. 保存到指定位置

### 创建 7z/RAR 压缩包
1. 打开压缩包处理工具
2. 选择源文件或目录
3. 选择"7Z"或"RAR"格式
4. 确保已安装相应的工具
5. 点击"创建压缩包"

### 配置自定义操作
1. 打开用户操作配置对话框
2. 点击"添加新操作"
3. 填写名称、命令、描述等信息
4. 保存配置
5. 在右键菜单中使用（需集成到主窗口）
